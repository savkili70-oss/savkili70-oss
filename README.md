## 🔊 Türkçe yapay zekâ: Kitap Evreni
Savunma Sanayii Başkanlığı'nın yapay zekâ platformu **EVREN** ile 100 telifsiz Türk klasiğini (52 saat) seslendirip internetsiz çalışan bir Android uygulamasında topladım.
EVREN'in Türkçe ses modelini (voxcpm2) düzenli olarak ölçüyorum: okunabilirlik (WER), bant genişliği, tonlama, hız.
